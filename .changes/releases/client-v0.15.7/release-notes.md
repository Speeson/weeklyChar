# KeystoneClient 0.15.7

## Correcciones

- El resumen de talentos muestra ahora el icono oficial de la especialización heroica.
  - Usa el atlas oficial de Blizzard asociado al Hero Talent activo.

# KeystoneClient 0.15.7

## Fixes

- The talent summary now displays the official Hero Talent specialization icon.
  - Uses Blizzard's official atlas art for the active Hero Talent.
  - Supports older snapshots that only include the Hero subtree identifier.
  - Keeps the first talent icon only as a fallback for unknown future specializations.
