# KeystoneClient 0.14.0

## Novedades

- La ventana se adapta al monitor y permite bloquear la proporción al cambiar su tamaño.
  - El tamaño inicial usa el espacio disponible sin superar el diseño habitual en monitores grandes.
  - Ajustes permite mantener la proporción durante el arrastre o conservar el cambio de tamaño libre.

## Correcciones

- Equipos recuerda el último equipo abierto al volver a iniciar el cliente.
  - La selección se guarda por usuario y se restaura si el equipo sigue disponible.
