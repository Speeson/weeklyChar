# KeystoneClient 0.18.0

## Cambios

- Reorganiza los ajustes del cliente en cuatro pestañas.
  - General, Account selection, Appearance y Application comparten una ventana de altura fija con pestañas y acciones siempre visibles, sin títulos repetidos dentro de cada pestaña.
  - La sección Tema visual muestra cinco tarjetas con vista previa y resaltado de la selección.
  - General organiza el inicio, el cierre, el overlay y la ventana con interruptores y un selector de cierre de tres opciones.
  - Application separa el idioma y la versión del cliente en secciones; el selector de idioma ocupa todo el ancho.

# KeystoneClient 0.18.0

## Changes

- Organizes client settings into four tabs.
  - General, Account selection, Appearance, and Application share a fixed-height dialog with tabs and actions that stay visible, without repeated titles inside each tab.
  - The Visual theme section presents five preview cards with a clear selected state.
  - General groups startup, closing, overlay, and window controls with switches and a three-choice close selector.
  - Application separates language and client version into sections; the language selector spans the full width.
