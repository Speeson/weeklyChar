# KeystoneClient 0.9.0

## Novedades

- Añade inicio de sesión seguro con Battle.net a KeystoneClient.
  - El cliente abre Battle.net en el navegador del sistema y completa el acceso mediante un flujo temporal de polling.
  - KeystoneClient conserva únicamente la sesión propia de KeystoneSync y no almacena tokens de Battle.net.
  - Ajusta la alineación óptica de las acciones Web y bandeja en español e inglés.
