# KeystoneClient 0.15.6

## Correcciones

- La pestaña Personajes ya no bloquea el cliente con datos antiguos o parciales.
  - Tolera listas ausentes o incompletas de equipo, gemas, talentos y mazmorras.
  - Mantiene la cabecera y los controles de ventana disponibles si una pestaña encuentra un error inesperado.
  - Permite volver a Sincronizar desde una vista de recuperación localizada.

# KeystoneClient 0.15.6

## Fixes

- The Characters tab no longer locks the client when it receives old or partial data.
  - Tolerates missing or incomplete equipment, gem, talent, and dungeon arrays.
  - Keeps the header and window controls available when a tab encounters an unexpected error.
  - Provides a localized recovery view that returns to Sync.
