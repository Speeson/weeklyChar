# KeystoneClient 0.11.2

## Correcciones

- Centra las composiciones incompletas del planificador sin alterar las posiciones por rol.
  - Centra horizontalmente las tarjetas visibles de la vista previa cuando se desactiva el relleno de composición.
  - Centra verticalmente en el detalle las parejas Tank/Healer o dos DPS que comparten una sola fila.
  - Mantiene intactas las posiciones habituales de Tank, Healer y DPS para composiciones completas o repartidas entre ambas filas.
