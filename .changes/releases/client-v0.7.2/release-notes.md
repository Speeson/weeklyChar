# KeystoneClient 0.7.2

## Correcciones

- Mejora el cierre de KeystoneClient y permite recordar la acción elegida.
  - Ajustes permite elegir entre preguntar, minimizar a la bandeja o cerrar la aplicación al cerrar la ventana.
  - El diálogo de cierre puede recordar la elección para solicitudes posteriores.
  - Una segunda pulsación de Alt+F4 mientras el diálogo está abierto confirma la salida y evita que el cliente quede bloqueado.
